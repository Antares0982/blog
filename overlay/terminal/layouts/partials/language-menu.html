This walks the site's languages instead and links the current page's translation when there is one. Most pages have none -- only python-json is translated so far -- so the fallback is still that language's home, but now it is the fallback rather than the rule. The current language is kept in the list to match how upstream renders, since the trigger shows it too. */}} {{- $page := . -}}
